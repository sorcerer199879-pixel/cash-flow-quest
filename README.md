# Cash Flow Quest

小規模事業の経営者として毎月の意思決定を行い、利益と現金の違いを体験するオリジナルの財務シミュレーションゲームです。PC・スマートフォンのブラウザで動作し、外部サーバーは不要です。

## 学べること

- 黒字でも売掛金・在庫の増加により資金不足になる仕組み
- 買掛金、回収・支払条件と運転資金の関係
- 借入・返済・設備投資が財務三表へ与える影響
- 固定費、安全余裕、営業CF・投資CF・財務CFの違い

## ゲームルール

1ターンは1か月です。月初にイベントを確認し、3アクションポイント以内で経営判断を選びます。初級・中級は24か月、上級は36か月。現金不足と低信用、3か月連続の債務超過、返済不能でゲームオーバーです。最終評価は成長性、安全性、流動性、営業CF安定性の総合点です。

同じ乱数シードと同じプレイ条件なら同じイベント抽選になります。毎月自動保存され、手動保存・再開・削除・同条件リトライが可能です。

## 財務計算

金額はすべて円単位の整数です。教育目的の簡略モデルで、売上は選択効果と成長率から計算します。売掛金は `売上 × 回収月数`、買掛金は `売上原価 × 支払月数` を目標残高とします。在庫は売上原価の変化と意思決定で増減します。

営業CFは次式です。

`税引後利益 + 減価償却費 - 売掛金増加 - 在庫増加 + 買掛金増加`

投資CFは設備投資額のマイナス、財務CFは借入－返済＋増資です。常に次式を満たします。

`月末現金 = 月初現金 + 営業CF + 投資CF + 財務CF`

設備は5年の定額法で簡略償却し、税金は税引前利益が正の場合に25%です。配当、消費税、繰越欠損金、債権別の回収台帳はMVPでは省略しています。

## 設定の変更・追加

難易度は `DIFFICULTIES`、アクションは `ACTIONS`、イベントは `EVENTS` を編集します。アクション効果は売上倍率、固定費、変動費率、成長率、在庫、回収・支払月数、設備投資、借入・返済・増資、信用スコアの組み合わせです。新しい項目を追加する場合は `ActionEffect` と `calculateMonth` を合わせて更新し、会計整合テストを追加してください。

## セーブ仕様

キーは `cash-flow-quest-save-v1`。`version`、保存日時、全 `GameState` をJSONで保存します。読み込み時はバージョンと必須構造を検証し、破損時はタイトル画面へ安全に戻ります。最高得点は別キーに保存します。

## ゲームバランス上の前提

基礎月商180万円、変動費率43%、月間固定費68万円から始まります。売上施策は売掛金と在庫需要を増やし、投資は当月の現金を減らして継続的な能力を作ります。現金の持ち過ぎだけでは成長点が伸びず、借入を避けるだけでも高得点にはなりません。
